# Baseline fidelity (SD-04)

The main text calls CBS/ECBS/PBS "grid proxies". The shipped `planner.py:_cbs_tree()`
is a *continuous* constraint-tree scheduler, so the two descriptions are opposite.

Two artefacts are provided:

* `grid_cbs_results.json` / `grid_cbs_summary.csv` - standard 3-D grid MAPF baselines
  (40 x 40 x 12 lattice, 5 m voxels, 12.5% obstacles, 6 agents, 20 instances per solver)
  obtained with open-source CBS/ECBS/PBS. This is the *discrete* reference point that
  justifies the "grid proxy" wording.
* The continuous constraint-tree implementation used for the main benchmark is
  described below; its numbers are the ones reported in main Tables II/VI.

| solver | state space | objective | timeout policy |
|---|---|---|---|
| CBS (grid) | discrete 5 m lattice, 12.5% obstacles | sum-of-costs / makespan | 5 s then unsolved |
| ECBS (grid) | same, bounded suboptimality w=1.5 | sum-of-costs | 5 s then unsolved |
| PBS (grid) | same, fixed priority ordering | makespan | 5 s then unsolved |
| CBS/ECBS/PBS (main benchmark) | continuous SE(3) constraint tree | makespan with separation d_min + eps_loc | 5 s MILP budget, never reached (Supp. Table S14) |
